# Resume Coach · 简历教练 Skill

> 灵感来源：抖音 @百分之21%《华为→腾讯，用14分钟讲讲写简历》（[视频链接](https://v.douyin.com/66SkaFvnWqo/)）。本仓库将其 13 个知识点整理成可执行的 AI Agent Skill，方法论版权归原博主，本仓库仅做结构化与工程化，遵循原视频精神：**只重构表达，不改事实**。

一个让你手上的 AI 变成"大厂用人侧简历筛选官"的 Skill：诊断、重构、逐条改写简历，核心信念是——**简历不是自传，是证据清单**。

## 它做什么

```
你的简历 + 目标 JD
      ↓
① 体检（空话 / 归属 / 数据口径 / 深挖 / 匹配 / 版式，最多 5 个问题）
② 定框架（1 页 · 单栏 · 校招/社招分别排序）
③ 逐条改写（动词 + 项目名称 + 问题 + 解决方案 + 量化成果）
④ 追问（列出你必须本人补充的 3 个事实，不编造）
⑤ 定稿 checklist（数据 / 深挖 / 匹配 / 排版 / 命名与保密）
```

## 核心写作公式

**动词 + 项目名称 + 问题 + 解决方案 + 量化成果**

| ❌ 反面 | ✅ 正面 |
|---|---|
| 负责订单交付管理 | 建立订单风险分级机制及异常交付预警看板，推动采购、仓储与供应商定期协同，提前识别并处理潜在交付风险 |
| 搭建体系 | 搭建区域需求预测和规划体系 |
| ROI 两年提升 35% | ROI 从 1.2 提升至 1.6（投放口径，不含自然流量），周期 18 个月 |
| 通过数据分析提升效率 | 通过用户行为分层、关键路径分析及 A/B 测试，联合产品团队优化新手引导流程 |

三条硬红线：每个数字能说清**分子分母**；每条经历撑得住**三层追问**（为什么做 → 怎么做 → 我个人做了什么）；**不编造**，缺事实让 AI 追问你补。

## 安装

### WorkBuddy / 兼容 Agent Skills 的客户端

```bash
# 用户级（跨项目可用）
mkdir -p ~/.workbuddy/skills
cp -r skills/resume-coach ~/.workbuddy/skills/

# 或项目级（随仓库共享）
mkdir -p .workbuddy/skills
cp -r skills/resume-coach .workbuddy/skills/
```

安装后直接说"帮我改简历"或"按这个 JD 优化我的简历"即可触发。

### 任何大模型（无需安装）

复制 [`PROMPT.md`](PROMPT.md) 全文粘贴到对话框，末尾附上【JD + 原始简历】即可。另有约 200 字的精简版在同文件内。

## 设计原则

- **不编造约束**：Skill 内置"缺事实必须追问用户、不许自行填充"，防止 AI 帮你编数字——这正是原视频批得最狠的一类简历。
- **五段固定输出**：体检表 → 新骨架 → 逐条改写（原句/改写/待补事实）→ 3 个追问 → 定稿 checklist。
- **Quick Mode**：只改一两段经历时跳过体检和框架，直接套公式。
