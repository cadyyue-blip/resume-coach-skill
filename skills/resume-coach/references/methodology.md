# Resume Coach 方法论 · 13 个知识点

来源：抖音 @百分之21%《华为→腾讯，用14分钟讲讲写简历》（2026-11-04，视频 ID 7704214658470792483），经逐帧还原整理。"3–5 秒"等为博主经验说法，非精确统计。

## 01 简历格式

### 1.1 页面规格
- 先定页数再定模块。10 年以内经验默认 1 页；不要靠堆页数显得"内容丰富"。
- 每一条内容都要为"3–5 秒内被看中"这个目标服务。

### 1.2 简历模板
- 反面案例：左右双栏模板，左栏塞满"联系方式/技能/教育/主修"，右侧才是工作经历——**"但其中的有效信息就两个"**，真正有价值的经历被压缩在右侧一小块区域。
- 结论：选简洁单栏模板；版式的作用是让信息被扫到，不是展示设计能力。

### 1.3 信息结构
- 校招与社招的模块顺序不同：校招前置教育/实习，社招前置工作经历。
- 排序原则：HR 最想先看什么，什么就放最前。

### 1.4 具体模块信息
- "其它"模块 = 技能证书、获奖（奖学金、专业竞赛奖项）、兴趣爱好、个人介绍。
- 个人介绍**必须和岗位相关**，写法："具有 XXX 经验，熟悉 XXX 流程"；不写形容词堆砌的自评。

## 02 简历内容

### 2.1 常见问题
视频使用的反面教材（某"高级感"简历原文）：

> 1. 负责核心产品的增长体系构建，通过用户生命周期管理与数据模型，主导用户规模从千万级至数亿级的跨越式增长。
> 2. 深度整合品牌内容与效果广告，搭建了"品效协同"的全球营销中台，使营销投资回报率（ROI）在两年内实现年均 35% 的提升。

三个致命问题：
1. 说不清具体做了哪一环——"是渠道投放？用户激活？还是留存提升？"
2. 全是平台/团队功劳，"直接证明你个人创造的价值有多少"缺失。
3. "你的 ROI 提升 35%，那它原来的基准是多少？"——数字没有基准和口径，等于没有。

### 2.2 写作方法（核心公式）

**动词 + 项目名称 + 问题 + 解决方案 + 量化成果**

| 要素 | 规则 | 正反例 |
|---|---|---|
| 动词 | 明确"我承担的责任"。优先：主导/搭建/推动/重构/优化/落地/复盘/协调 | 反例：负责（裸奔）、参与 |
| 项目名称 | 具体到业务对象，空壳词不能单独出现 | "搭建体系" → "搭建区域需求预测和规划体系" |
| 问题 | 谁的、哪个指标、出了什么问题 | "针对新注册用户首周留存偏低" |
| 解决方案 | 具体动作 + 方法论，能被追问 | "通过用户行为分层、关键路径分析及 A/B 测试，联合产品团队优化新手引导流程"；反例："通过数据分析提升效率" |
| 量化成果 | 涨幅 + 基准 + 口径 + 周期 | 反例："ROI 两年提升 35%"；正例："ROI 从 1.2 提升至 1.6（投放口径，不含自然流量），周期 18 个月" |

完整改写示例：
- 原："负责订单交付管理"
- 改："建立订单风险分级机制及异常交付预警看板，推动采购、仓储与供应商定期协同，提前识别并处理潜在交付风险"

### 2.3 案例修改
完整示范句：
> 优化新用户激活策略：针对新注册用户首周留存偏低的问题，通过用户行为分层、关键路径分析及 A/B 测试，联合产品团队优化新手引导流程，最终……

"没什么可写"是错觉：连"推动楼梯间环境改善项目"这种小事，套上"动词+项目名称"再补齐问题/方案/结果，也是一条有效经历。

## 03 注意事项

### 3.1 数据
每个数字都要能回答**"它的分子分母是什么"**。口径说不清的数据是负分。

### 3.2 深挖
一条经历要能被追问三层；**"要不干脆就别写"**——撑不住三层追问的经历删掉，别占版面。

### 3.3 匹配
按目标 JD 调整措辞与排序，但**"也不是说要从头到尾彻底改掉"**——只重构表达，不改事实。

### 3.4 排版
**"一份简历里面不要出现四五种字体"**；同类信息（公司名、学校名）统一加粗、字号略大。

### 3.5 文件格式、命名与信息保密
- 导出 PDF。
- 命名要让人翻邮箱时一眼认出你是谁、投什么岗：`姓名-目标岗位-年限-核心亮点.pdf`。
- 对外版本隐去客户名、内部系统名、未公开数据，用"某头部快消客户""内部 XX 系统"替代。

## 常见问答

**Q：没有量化数据怎么办？**
A：用覆盖面（覆盖 X 家门店 / 影响 Y 万用户）、相对值（缩短 Z 天）、或注明估算口径的范围值。绝不编造。

**Q：经历很琐碎，值得写吗？**
A：小事也能套公式。先问自己：这件事里"我"做了什么决定、解决了什么问题？有答案就写，没有就删。

**Q：要不要为每个岗位改一版？**
A：要。匹配原则要求按 JD 关键词重排措辞与模块顺序，但事实层面保持一致，避免不同版本自相矛盾。
